# Privacy

ProtoInputMultiPlex processes configured input locally to support independent
users and explicitly selected applications. Profiles, preferences, macros and
optional diagnostic artifacts are stored on the computer. OCR and image matching
use local processing and bundled model files.

Optional MCP and loopback command SDK connections expose only the capabilities
the operator enables and grants. Browser origins require explicit configuration.
Input, captures or other command results may be received and retained by a client
the operator connects; that client's own privacy policy applies. Connection
descriptors contain credentials and should remain private.

The application does not automatically send diagnostics, captures or input to
the project maintainer. Network access requested by an operator or an explicitly
connected client should be assessed in that client's environment. Windows and
other third-party software have their own privacy policies.

The proposed release-signing application shares maintainer contact information
and public project/build information with SignPath, separately from application
operation. See [SignPath's privacy policy](https://signpath.io/privacy-policy).
