A real invalid Apply disabled receipt and visible error, Revert, and successful Apply preserve complete preferences/profile values. |
| Shared native dispatch | Reference the combined-image lifecycle gate's real Home Start and healthy Stop/native-UP result and owned active-Home image. Do not launch another native feature-family suite for layout. This criterion remains unaccepted unless that lifecycle evidence passes on the same image. |
