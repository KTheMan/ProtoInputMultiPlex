# Connected Macro Studio recording contract

Connected client-attributed recording passed a bounded virtual assessment: [six native groups, 14 named outcomes, 28 GUI receipts, three frames and two x64 targets](connected-macro-recording-assessment-2026-10-15.json); i686 was not executed. The frozen producer passed 171 workspace tests plus formatting, strict Clippy and x64/i686 builds ([record](connected-macro-recording-rust-checks-2026-10-14.json)). The existing `macro_studio` tool and 23-tool schema expose per-user Record Start/Stop under the current Agent Access session-change grant. Inspect is read-only and does not require that grant. Start requires an active permitted virtual user, that user's selected allowed target, an idle lane, and no held input on that user; holds on other users do not block it. Stop is limited to the recording client and does not require current focus. The GUI shows agent-recording ownership, event count and recording errors; local Stop is unavailable for an agent-owned take. Its local **Discard agent recording** action discards only the uncommitted take and leaves the agent connection running.

Recording captures one raw logical action only after the owner's complete action succeeds, before output conversion. Disabled/intercepted output may still be recorded as an accepted source action; replicated copies are not recorded again. This does not guarantee the target application consumed the action. Batch preflight failure records no events, but earlier successful batch members may already be delivered and recorded if a later member fails. Partial text effects cannot be rolled back. Recorder capacity is checked before delivery; an overflowing action is rejected before emission and the candidate is discarded. If recorder capture unexpectedly fails after successful delivery, the error states that delivery already happened and must not be blindly retried.

A nonempty valid Stop commits the candidate clip. Empty or invalid takes preserve the previous clip and revision and return an error surfaced in recording state. Disconnect/EOF and that client's connected `ReleaseAll` discard only its unfinished take; local session `ReleaseAll` remains session-wide. Policy revocation or global Stop/Pause/Mode discard active takes. Ordinary lane edits and settings changes that interrupt recording reject while it is active; explicit local Discard is allowed. Clips remain session-local and are never saved to profiles. This recording result supplements the earlier connected Macro Studio assessment, which remains evidence for its separately tested authoring/playback scope.
